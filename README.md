# 💻 Dave - 你的 macOS 桌面工程师小宠物 (Desktop Pet)

**Dave** 是一只常驻在 macOS 桌面的像素风工程师小宠物。他穿着经典的科技蓝连帽衫，戴着黑框眼镜，手里总少不了一杯热咖啡或一台发光的笔记本。

专为开发者设计，采用 **SwiftUI + AppKit** 原生打造，极轻量（内存占用 < 30MB，二进制体积仅 370KB），不抢占 IDE 焦点。

---

## ✨ 核心特性 (MVP v1.0)

### 1. 像素风状态动画系统
* **摸鱼待机 (Idle)**：端着热咖啡眨眼、呼吸，悠闲站立。
* **疯狂码字 (Coding)**：键盘噼里啪啦飞舞，屏幕代码与灵感粒子四溢。
* **抓虫思考 (Debugging)**：挠头苦思，黄色问号与红色 Bug 飞舞。
* **品味咖啡 (Coffee)**：举杯畅饮热咖啡，冒出治愈蒸汽与满足的 `^ ^` 笑容。
* **午休小憩 (Sleeping)**：蜷缩趴着打呼，头顶浮动可爱的 `Zzz` 气泡。
* **被抓悬空 (Dragged)**：鼠标拖拽或空中甩飞时双腿慌乱摆动，眼神震惊。
* **全力飞奔 (Running)**：Dave 身体前倾，甩开双臂快速奔跑。
* **满头大汗 (Sweating)**：CPU 狂飙负载 > 75% 时满头大汗、电脑发烫冒火星、狂扇小扇子。
* **庆祝搞定 (Celebrating)**：彩带飞舞，举起双手开心比 V！

### 2. 🌟 标志性特色功能

#### A. 与 Dave 对话并调用 Antigravity 协同工作 (AI Copilot Bridge - 全双向实时同步)
* **独立悬浮交互面板**：点击 Dave 头顶的「**💬 对话**」药丸胶囊、右键选择「**与 Dave 对话**」或点击菜单栏图标即可唤出极客风对话窗。
* **直接下达任务**：输入你想做的事（如*“帮我检查当前 Git 变更”*、*“写一个 Python 贪吃蛇游戏”*、*“执行项目构建与测试”*）。
* **底层直连 Antigravity**：Dave 动态发现正在运行的 Antigravity 会话，通过官方 `agentapi` 接口实时将任务派发至会话大脑！
* **全双向实时工作状态同步 & 动态动画切换**：
  * **在 Antigravity 直接发任务** 或 **在 Dave 中发任务** 均可实现 100% 毫秒级双向感知！
  * **思考规划需求时**：Dave 切换为 **抓虫思考 (`debugging`)** 动画，挠头苦思并浮现黄色问号与红色 Bug，提示「正在深入思考架构与解题方案... 🧠」；
  * **修改与编写代码时 (`edit_file` / `write_file`)**：Dave 切换为 **疯狂码字 (`coding`)** 动画，坐在发光的笔记本前飞速敲击键盘并四溢代码粒子，提示正在编写的具体文件；
  * **执行终端命令与构建测试时 (`run_command`)**：Dave 保持 **疯狂码字 (`coding`)** 动画，屏幕闪烁光晕，气泡提示执行的命令概要；
  * **查阅代码与搜索资料时 (`read_file` / `search_web` / `list_resources`)**：Dave 切换为 **抓虫思考 (`debugging`)** 动画，气泡展示检索内容；
  * **任务圆满完成时 (`Stop` / `CASCADE_RUN_STATUS_IDLE`)**：Dave 立即跃起进入 **庆祝搞定 (`celebrating`)** 姿态，彩带飞舞比出胜利 V 手势，播放欢呼音效，并在 3.8 秒后优雅切回待机状态！
  * **支持外部脚本与 Hook 联动**：内置 `dave-sync` 生命周期 Hook 插件与 `./scripts/sync_status.sh`。

#### B. 顶部状态栏实时 Token 消耗统计面板 (Token Usage HUD)
* **状态栏弹窗常驻**：点击系统顶部状态栏的 `💻 Dave` 图标，弹窗顶部即刻呈现精致的 **Token 消耗统计卡片**。
* **双维度全方位数据**：
  * **当前会话维度**：实时展示输入 Token (`Prompt`)、输出 Token (`Output`)、缓存命中 Token (`Cache Read`) 与总计调用步数；
  * **今日累计维度 (24h)**：全自动统计过去 24 小时内所有 Antigravity 会话的总消耗量与缓存节省量；
* **极速无感统计**：基于底层增量解析，单次统计计算仅需 15ms，绝不卡顿系统或 IDE。
* **伴随对话窗实时显示**：在独立对话面板右上角亦配有当前 Token 消耗胶囊，一目了然。

#### C. 屏幕边缘贴靠与探头 (Edge Snapping & Peeking)
* **自动磁吸贴边**：拖拽 Dave 靠近屏幕最左侧或最右侧边缘松开，自动顺滑缩进屏幕边缘，只留出一张戴黑框眼镜的呆萌小脸探头偷看；
* **悬停探头互动**：鼠标移到露出的头部上方（Hover），Dave 自动欢呼跳出屏幕边缘探出身子；鼠标移开后 2 秒无操作再次乖巧退回边缘，绝不遮挡核心代码与 IDE 视线；
* **随心拖拽脱离**：往屏幕内侧稍用力拖动，即可脱离贴靠模式恢复自由浮动。

#### D. Mac 硬件与电源环境感知 (Hardware & Power Observer)
* **原生微秒级 Mach CPU 监听**：基于底层的 `host_processor_info` 毫秒级原生接口，无子进程无额外负载；
* **高负载狂飙与扇风动作**：连续检测到 CPU 占用率 > 75% 时，Dave 切换为「满头大汗扇小扇子」状态，笔记本屏幕发烫发红并冒出火星粒子，气泡吐槽；当负载回落至 < 60% 时长舒一口气恢复正常；
* **MagSafe / USB-C 充电充能联动**：插上电源充电瞬间，Dave 立即触发闪电充能声效与跃起弹跳；
* **低电量预警守护**：电池电量 < 20% 且未接电源时，Dave 及时提醒求插座救命；
* **内置调试模拟器**：支持在右键菜单或顶部状态栏一键模拟高负载狂飙与插电效果！

### 2. 原生桌面伴侣体验
* **透明悬浮无边框**：无缝融入桌面壁纸，不遮挡其他窗口。
* **不抢焦点 (Non-activating)**：无论怎么戳 Dave，你的 VS Code、Xcode、Terminal 都不会失去光标焦点。
* **跨桌面常驻 (Multi-Space)**：支持所有虚拟桌面与全屏应用间穿梭保持显示。
* **随心拖拽**：鼠标按住直接在屏幕各处拖放，松开自带 Q 弹着陆音效与弹性动效。
* **对话气泡 (Speech Bubble)**：点击 Dave 会触发幽默的程序员神回复与贴心提醒。
* **顶部状态栏伴侣 (Menu Bar)**：常驻系统顶部状态栏，方便一键召唤、隐藏与切换状态。
* **工休与喝水提醒 (Health Reminder)**：定时贴心提示离开座椅活动颈椎。

## 🚀 编译与运行

### 方式一：开发模式直接运行
在终端中进入项目根目录：
```bash
# 启动 Dave
swift run
```

### 方式二：一键打包为原生 `Dave.app`
运行内置的打包脚本：
```bash
# 编译并生成独立 macOS 应用
chmod +x scripts/build_app.sh
./scripts/build_app.sh

# 启动生成好的 App（也可以直接拖入 /Applications 应用程序目录）
open build/Dave.app
```

## 🎨 像素资产生成器

如果你想要调整 Dave 的衣服颜色、饰品或像素动作，可以直接修改 `scripts/generate_sprites.py`，然后运行：
```bash
python3 scripts/generate_sprites.py
```
所有状态的透明 PNG 序列帧均会自动重新生成并按像素级完美对齐。
