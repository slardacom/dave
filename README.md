# 💻 Dave - 你的 macOS 桌面工程师小宠物 (Desktop Pet)

**Dave** 是一只常驻在 macOS 桌面的像素风工程师小宠物。他穿着经典的科技蓝连帽衫，戴着黑框眼镜，手里总少不了一杯热咖啡或一台发光的笔记本。

专为开发者设计，采用 **SwiftUI + AppKit** 原生打造，极轻量（内存占用 < 30MB，二进制体积仅 370KB），不抢占 IDE 焦点。

---

## ✨ 核心特性 (MVP v1.0)

### 1. 像素风状态动画系统 (10 种专属状态)
* **摸鱼待机 (Idle)**：端着热咖啡眨眼、呼吸，悠闲站立。
* **疯狂码字 (Coding)**：键盘噼里啪啦飞舞，屏幕代码与灵感粒子四溢。
* **抓虫思考 (Debugging)**：挠头苦思，黄色问号与红色 Bug 飞舞。
* **品味咖啡 (Coffee)**：举杯畅饮热咖啡，冒出治愈蒸汽与满足的 `^ ^` 笑容。
* **午休小憩 (Sleeping)**：蜷缩趴着打呼，头顶浮动可爱的 `Zzz` 气泡。
* **被抓悬空 (Dragged)**：鼠标拖拽时被揪起，双腿慌乱摆动，眼神震惊。
* **全力飞奔 (Running)**：Dave 身体前倾，甩开双臂快速奔向目标文件。
* **抱起文件 (Carrying)**：头顶高举待删除文件/代码文档，飞奔向 Dock 栏。
* **暴扣垃圾桶 (Throwing)**：跳起三分暴扣将文件狠狠砸进废纸篓！
* **庆祝搞定 (Celebrating)**：彩带飞舞，举起双手开心比 V！

### 2. 🌟 标志性特色功能

#### A. 与 Dave 对话并调用 Antigravity 协同工作 (AI Copilot Bridge)
* **独立悬浮交互面板**：点击 Dave 头顶的「**💬 对话**」药丸胶囊、右键选择「**与 Dave 对话**」或点击菜单栏图标即可唤出极客风对话窗。
* **直接下达任务**：输入你想做的事（如*“帮我检查当前 Git 变更”*、*“写一个 Python 贪吃蛇游戏”*、*“执行项目构建与测试”*）。
* **底层直连 Antigravity**：Dave 通过官方 `agentapi` 接口实时将任务派发至当前的 Antigravity Agent 会话大脑！
* **工作状态实时同步与“忙碌码字”姿势**：
  * 当 Antigravity 开始执行任务时，Dave 立即切换到 **疯狂码字 (`coding`)** 状态，坐在发光的笔记本电脑前飞速敲击键盘，屏幕代码光晕闪烁；
  * 任务完成时，Dave 立即跃起进入 **欢呼庆祝 (`celebrating`)** 姿态，弹出完成气泡，并无缝切回待机状态！
  * 支持外部脚本与 CI/CD 联动状态同步：`./scripts/sync_status.sh busy "正在跑单元测试..."` 与 `./scripts/sync_status.sh idle "测试通过"`。

#### B. 文件删除搬运入桶联动 (Trash Duty)
* **自动监听**：内置 `FileTrashMonitor` 监控桌面与下载文件夹中的文件删除事件，以及全局 `Cmd + Delete` 快捷键。
* **仿真全套跑腿**：通过 `FileGhostWindow` 保持被删文件的视觉分身，Dave 飞奔过去抱起真实文件图标，一路小跑至 Dock 栏废纸篓投掷入桶！
* **直接拖拽投喂**：支持将任意桌面文件直接拖放到 Dave 身上，Dave 亲自代跑废纸篓！

### 2. 原生桌面伴侣体验
* **透明悬浮无边框**：无缝融入桌面壁纸，不遮挡其他窗口。
* **不抢焦点 (Non-activating)**：无论怎么戳 Dave，你的 VS Code、Xcode、Terminal 都不会失去光标焦点。
* **跨桌面常驻 (Multi-Space)**：支持所有虚拟桌面与全屏应用间穿梭保持显示。
* **随心拖拽**：鼠标按住直接在屏幕各处拖放，松开自带 Q 弹着陆音效与弹性动效。
* **对话气泡 (Speech Bubble)**：点击 Dave 会触发幽默的程序员神回复与贴心提醒。
* **顶部状态栏伴侣 (Menu Bar)**：常驻系统顶部状态栏，方便一键召唤、隐藏与切换状态。
* **工休与喝水提醒 (Health Reminder)**：定时贴心提示离开座椅活动颈椎。

## 🚀 编译与运行

### 方式一：开发模式直接运行
在终端中进入项目根目录：
```bash
# 启动 Dave
swift run
```

### 方式二：一键打包为原生 `Dave.app`
运行内置的打包脚本：
```bash
# 编译并生成独立 macOS 应用
chmod +x scripts/build_app.sh
./scripts/build_app.sh

# 启动生成好的 App（也可以直接拖入 /Applications 应用程序目录）
open build/Dave.app
```

## 🎨 像素资产生成器

如果你想要调整 Dave 的衣服颜色、饰品或像素动作，可以直接修改 `scripts/generate_sprites.py`，然后运行：
```bash
python3 scripts/generate_sprites.py
```
所有状态的透明 PNG 序列帧均会自动重新生成并按像素级完美对齐。
